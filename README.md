# Dream Butterfly

A web application for creating and sharing age progression videos using AI.

## Features

- **User Management**: Register and login functionality
- **AI Video Generation**: Upload up to 20 images and generate age progression videos using AI API
- **Video Management**: Users can manage their generated videos and set privacy settings
- **Video Sharing**: Watch videos generated by other users

## Technology Stack

- **Frontend**: Vue 3
- **Backend**: Rust
- **Database**: MySQL
